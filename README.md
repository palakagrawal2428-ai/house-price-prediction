# House Price Prediction

Machine learning project jo California ke ilaakon ki median house price predict karta hai.

## Dataset
California Housing dataset (scikit-learn), 20,640 rows aur 9 columns.

## Kya kiya
- Data explore kiya: missing values check ki, outliers pehchaane
- Do models compare kiye: Linear Regression aur Random Forest

## Results
| Model | R2 Score | Average Error |
|---|---|---|
| Linear Regression | 0.576 | $53320 |
| Random Forest | 0.805 | $32754 |

## Tools
Python, pandas, numpy, matplotlib, scikit-learn
